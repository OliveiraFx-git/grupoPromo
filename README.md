# Site CTA — OFERTA+

Landing page estática responsiva para captar membros para um grupo de promoções no WhatsApp.

## Personalizar o link do WhatsApp
1. Abra `index.html`.
2. No final do arquivo, encontre:
   `const WHATSAPP_GROUP_LINK = "https://chat.whatsapp.com/COLE_SEU_LINK_AQUI";`
3. Substitua pelo link real de convite do grupo.
4. Salve o arquivo.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `site-promocoes`.
2. Envie `index.html` e `README.md` para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço público nessa mesma página.

## Personalização recomendada antes de divulgar
- Troque o nome provisório `OFERTA+` pelo nome definitivo da marca.
- Use apenas promessas verdadeiras. O texto atual não promete descontos específicos nem resultados garantidos.
- Confira o convite do grupo e teste todos os botões no celular.
